Check spelling in WordPress posts with a local Hunspell dictionary. For full website scans, visit https://sitespellchecker.com/.

== Description ==

Site Spell Checker adds a spelling panel to the WordPress block editor. It checks the current post using Typo.js and an English Hunspell dictionary, entirely in your browser. Post content is not uploaded to Site Spell Checker.

The plugin also includes a direct link to a full website scan at SiteSpellChecker.com. A footer credit is optional and disabled by default; administrators can opt in under Settings → Site Spell Checker.

== Installation ==

1. Upload the `spellcheck-wordpress-plugin` folder to `/wp-content/plugins/`.
2. Activate Site Spell Checker in the Plugins screen.
3. Open a post in the block editor and select the Site Spell Checker panel from the editor sidebar.

== Frequently Asked Questions ==

= Does the plugin send my content to a server? =

No. The current post and dictionary are processed locally in your browser.

= Can it scan every page on my site? =

The editor panel checks the post currently open. Use the whole-site scan link for a crawl and report across your site.

= How do I show the footer link? =

Go to Settings → Site Spell Checker and opt in to showing the footer credit.
